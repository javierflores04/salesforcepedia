# Salesforcepedia

A structured reference for Salesforce architecture patterns, Agentforce, Data Cloud, integration flows, and CTA board exam tracking.

## Live site
https://salesforcepedia.com

## Modules
- **Agentforce Architecture** — Hybrid reasoning model, blueprint hierarchy, deterministic sandwich, Classic Model vs Agent Script
- **Data 360 Architecture** — Ingest patterns, DLO/DMO data model, identity resolution, AI grounding, governance, multi-org strategy
- **Auth Flows** — Step-by-step walkthroughs of OAuth 2.0 flows, JWT Bearer assertions, and token lifecycle management
- **CTA Progress Tracker** — Log mock presentations, score rubric areas, track progress toward the CTA board passing thresholds
